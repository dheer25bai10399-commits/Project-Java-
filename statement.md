# Project Statement

## Project Title
Student Grade Management System

## Problem

Keeping student details and marks on paper or in separate files can become difficult when the number of students increases. It is also easy to make mistakes while calculating totals, averages and grades.

## Proposed Solution

The Student Grade Management System is a Java console application that keeps student details in one place. It allows the user to add students, enter their marks, calculate results and generate a class report.

## Target Users

The project is mainly intended for teachers, tutors or students who want a simple way to manage academic records.

## Scope

The current version supports:

- Student record management
- Marks entry
- Result calculation
- Student search
- Class report
- Saving and loading records using a text file

The project is kept as a console application so that the main focus stays on Java programming concepts.

## Main Modules

### 1. Student Management
Add, view, update, delete and search student records.

### 2. Marks and Result Management
Enter marks for five subjects and calculate total, average, grade and pass/fail status.

### 3. Reports
Show the number of students, highest scorer, class average and a list of student results.

### Non-functional requirements

- The program should give clear messages for invalid input.
- Records should be stored in a simple file without losing data after the program closes.
- The code should be divided into packages and classes.
- The application should be easy to use from the console.
