# Requirements

## Functional Requirements

1. Add student
2. View students
3. Update student
4. Delete student
5. Search student
6. Enter marks
7. Calculate result
8. Generate class report
9. Save records
10. Load records

## Non-Functional Requirements

- Easy to use
- Basic error handling
- Modular code
- Simple file storage
- Reasonable memory usage
- Maintainable package structure
